# Domain docs

This repository uses a single-context domain documentation layout.

## Before exploring

- Read `CONTEXT.md` at the repository root when it exists.
- Read relevant architectural decisions under `docs/adr/` when they exist.
- If either location is absent, continue without reporting the absence as an error.

Use vocabulary defined in `CONTEXT.md` in tests, plans, issues, and implementation. If a proposed change conflicts with an ADR, surface the conflict explicitly instead of silently overriding it.
